## 4. 与真实低分问卷的匹配结果

验证集共 6,415 条问卷，其中真实低分 832 条，真实低分率为 12.97%。

### 4.1 混淆矩阵

| 真实/识别 | 识别为潜在低分 | 未识别为潜在低分 | 合计 |
| --- | ---: | ---: | ---: |
| 真实低分 | TP 731 | FN 101 | 832 |
| 真实非低分 | FP 4,184 | TN 1,399 | 5,583 |
| 合计 | 4,915 | 1,500 | 6,415 |

| 匹配指标 | 结果 | 解释 |
| --- | ---: | --- |
| Precision | 14.87% | 圈选用户中约 14.87% 为真实低分 |
| Recall | 87.86% | 覆盖了 87.86% 的真实低分问卷 |
| Specificity | 25.06% | 正确排除了 25.06% 的真实非低分问卷 |
| Accuracy | 33.20% | 受低分样本不均衡影响，不宜单独判断效果 |
| F1 | 25.44% | precision 与 recall 的综合指标 |
| Jaccard | 14.57% | 预测低分集合与真实低分集合的交并比 |
| Lift | 1.15 | 圈选客群低分率为总体低分率的 1.15 倍 |

总体规则呈现明显的“高召回、低精度”：漏掉的真实低分仅 101 条，但额外圈入了 4,184 条真实非低分。与直接按总体低分率圈选相比虽有提升，但区分能力有限。

| 投诉高风险型 | 1,418 | 332 | 23.41% | 39.90% | 29.51% | 1.81 |
| 家宽体验风险型 | 536 | 131 | 24.44% | 15.75% | 19.15% | 1.88 |

| 套餐资费不满疑似型 | 2,135 | 333 | 15.60% | 40.02% | 22.45% | 1.20 |

| 提醒告知不足疑似型 | 48 | 13 | 27.08% | 1.56% | 2.95% | 2.09 |
| 高频触点负面型 | 487 | 161 | 33.06% | 19.35% | 24.41% | 2.55 |

主要观察：

1. **投诉未解决疑似型的纯度最高。** Precision 37.44%、Lift 2.89，适合形成较高优先级的人工复核名单，但覆盖率只有 9.86%。
2. **高频触点负面型和办理受阻型具有较强区分度。** Lift 分别为 2.55 和 2.39，明显高于流量、资费类规则。
3. **流量超套型贡献了主要召回。** Recall 达 75.00%，但 Precision 仅 15.44%、Lift 仅 1.19，是总体圈选面过宽的主要来源。
4. **套餐资费型同样偏宽。** 覆盖 2,135 条问卷，但 Lift 仅 1.20，需要降低普通结构化订退订事件的权重。
5. **提醒不足和营销争议覆盖很低。** 当前规则分别只识别 48 和 284 条问卷，不能承担总体低分覆盖任务。

## 5. 结论与建议

### 5.1 结论

- 当前版本能发现绝大多数真实低分用户，Recall 87.86%，适合用于宽口径风险筛查。
- 当前总体匹配度仍偏低，F1 为 25.44%、Jaccard 为 14.57%，不适合作为自动定性或直接考核依据。
- 文本与强负面触点规则的 Lift 更高；单纯流量超套、订退订和套餐变化规则覆盖过宽。
- 评测数据只有一个调查月，无法判断跨月稳定性，现有指标不能替代跨批次验证。

### 5.2 调优优先级

1. 将“流量超套风险”拆分为普通事实风险与“不满风险”。仅结构化超套保留为弱/中证据，叠加投诉文本、负面触点、连续多月超套或高超套费用后再进入高优先级名单。
2. 收紧套餐资费规则。重复订购、单次退订或降档不应单独形成强结论，建议要求短期反复操作与资费负面文本共同命中。
3. 对外提供分层名单：高精度层优先采用投诉未解决、高频负面触点和办理受阻；高召回层保留流量及套餐风险用于二次筛查。
4. 逐条复核 `rule_validation_detail.csv`中的 4,184 条 FP 和 101 条 FN，并通过 `customer_key`关联 `potential_low_evidence.csv`定位规则原因。
5. 至少使用多个调查月或独立批次复测，分别报告每月 Precision、Recall、F1、Jaccard 和 Lift，再冻结下一规则版本。

## 6. 使用限制

- 风险类型表示规则证据，不等同于已经确认的不满意原因。
- 多类型命中存在重叠，类型人数不能直接求和。
- 问卷验证按调研月份起点截断，若获得精确调研时间，应改用精确时间重新验证。
- 本报告只描述当前批次和当前规则版本，不应外推为其他批次的固定结论。
