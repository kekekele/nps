## 4. 与真实低分问卷的匹配

验证集共有 6,415 条问卷，真实低分 832 条，真实低分率为 12.97%。验证按每条问卷的调研月份回看历史行为，未使用问卷评分、子问题或 Q99 参与识别。

### 4.1 混淆矩阵

| 真实/预测 | 预测低分 | 预测非低分 | 合计 |
| --- | ---: | ---: | ---: |
| 真实低分 | TP 133 | FN 699 | 832 |
| 真实非低分 | FP 232 | TN 5,351 | 5,583 |
| 合计 | 365 | 6,050 | 6,415 |

| 指标 | 结果 | 解释 |
| --- | ---: | --- |
| Precision | 36.44% | high 名单中真实低分占比 |
| Recall | 15.99% | 真实低分覆盖比例 |
| Specificity | 95.84% | 真实非低分正确排除比例 |
| Accuracy | 85.49% | 受样本不均衡影响，不单独作为结论 |
| F1 | 22.22% | Precision 与 Recall 的综合指标 |

| Lift | 2.81 | high 名单低分率为总体低分率的 2.81 倍 |

v3 明显收紧了名单：高优先级验证样本仅 365 条，FP 为 232 条；但为提升精度付出了较大召回代价，FN 为 699 条。

## 8. 证据分布与后续建议

证据行数最多的规则是 `REPEAT_SUBSCRIPTION`（13,289）、`SUBSCRIPTION_CANCEL`（7,124）、`COMPLAINT_NO_OVERAGE_SPECIAL`（3,606）、`PLAN_DOWNGRADE`（2,650）和 `HOME_BROADBAND_BANDWIDTH_LT_500`（2,312）。这些是影响各层名单规模的主要来源。

建议按业务容量使用：

1. 容量小且优先精度时，使用 high 393 人生产名单，并优先处理其中存在“投诉未解决”“高频负面触点”“办理受阻”证据的用户。
2. 需要兼顾覆盖时，使用 high+medium；其验证 Recall 31.25%、Precision 25.97%。
3. watch 低分率仅略高于总体，不建议单独作为主动服务名单，可作为叠加营销、地域或时效条件后的观察池。
4. v3 当前仅有 2026-08 一个验证月，需用后续月份或独立批次验证后再冻结规则。

## 9. 使用限制

- 风险类型代表数据证据，不等同于已确认的不满意原因。
- 同一用户可命中多种风险类型，类型人数不能相加。
- 当前验证以调研月份起点为截止，获得精确调研时间后应重新验证。
- 家宽带宽规则适合当前生产快照识别；缺少历史快照生效时间时，不可用于历史问卷回测。
